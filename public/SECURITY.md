# Security Policy

## Contact Information

If you discover a security vulnerability within this project, please send an email to ahmeddalhalabi1@gmail.com. All security vulnerabilities will be promptly addressed.

## Supported Versions

We take security seriously and will address vulnerabilities in the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

To report a security vulnerability, please include:

1. A description of the vulnerability
2. Steps to reproduce the issue
3. Potential impact of the vulnerability
4. Suggested remediation (if any)

Thank you for helping keep our project secure!
